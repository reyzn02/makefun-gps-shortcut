A one-line excuse from a smug, defensive GPS that blames the map for sending the driver down the wrong road — through a wedding, a cul-de-sac, and, legally speaking, a lake. Written for make.fun's "The GPS Swears It Was a Shortcut" bounty. The program writes the single line (114 characters) to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
